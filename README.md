## What is XMB 420?

XMB 420 is a powerful Termux-based script manager for Car Parking Multiplayer that lets you:
- **Download CPM scripts** organized by game version (4.9.10 - 5.3.0) directly from GitHub
- **Encrypt your own Lua scripts** with AES-256-CBC encryption
- **Decrypt scripts** using your encryption key
- **Manage scripts** in dedicated folders
- **Launch CPM Cheats** directly from the menu
- **Purchase premium scripts** via Telegram
