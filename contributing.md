# Contributing to XMB 420

Thank you for your interest in XMB 420! While we appreciate community involvement, please note:

---

## 🙋‍♂️ Script Management

**Only the repository maintainer adds scripts to the repo.**  
However, users can **request scripts** by opening an issue with the script file attached.

---

## How to Request a Script

1. Open a **Script Request** issue
2. Include:
   - Script Name
   - CPM Version
   - Script Description
   - **Attach the .lua file** (drag and drop)
3. I'll review it and decide if it will be added

---

## Script Review Process

When you submit a script request, I'll check:

| Criteria | Description |
|----------|-------------|
| ✅ Functionality | Does the script work? |
| ✅ Safety | No malicious code |
| ✅ Formatting | Follows our style guide |
| ✅ Usefulness | Beneficial for other users |
| ✅ Compatibility | Works with the specified version |

---

## Script Request Template

Use the **Script Request** template which includes:
- Script name
- CPM version
- Description
- File attachment
- Additional details

---

## How You Can Contribute

| Contribution | Allowed? | Details |
|--------------|----------|---------|
| 🐛 Bug Reports | ✅ Yes | Use bug report template |
| 💡 Feature Suggestions | ✅ Yes | Use feature request template |
| 📝 Script Requests | ✅ Yes | Attach .lua file for review |
| 📝 Documentation Fixes | ✅ Yes | Submit PR for typos/improvements |
| 📚 Help Other Users | ✅ Yes | Answer issues and questions |
| 🔧 Code Improvements | ⚠️ Ask First | Open issue to discuss |
| 📥 Script Additions | ❌ No | Added by maintainer only |
| 📦 New Versions | ❌ No | Added by maintainer only |

---

## Pull Request Process

1. Fork the repository
2. Create a new branch
3. Make your changes (documentation only)
4. Commit your changes
5. Push and open a Pull Request

### Documentation Only

We accept PRs for:
- README improvements
- Typo fixes
- Better explanations
- Translation support

### Code Changes

For code changes:
1. Open an Issue first
2. Discuss the change
3. Get approval
4. Then submit PR
