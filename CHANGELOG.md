## [1.0] - 2026-01-03

### 🎉 Initial Release

**Added:**
- Initial release of XMB 420
- Support for 8 CPM versions (4.9.10 - 5.3.0)
- 9 scripts per version including SeKoPrimeCP1-2
- AES-256-CBC encryption
- Decryption functionality
- TUI interface with loading screen
- Download and encrypt features
- Settings management
- About section

**Features:**
- Download individual or all scripts
- Encrypt local or downloaded scripts
- Decrypt encrypted scripts
- View downloaded and encrypted scripts
- Change default encryption key
- Set GitHub username
- Clear downloaded scripts

**Security:**
- AES-256-CBC encryption via OpenSSL
- Auto-generated encryption keys
- Secure script storage

**Scripts Included:**
- 💰 Money Script
- 🚀 Speed Script
- 🔓 Unlock Script
- 💎 Gems Script
- 🏎️ No Clip Script
- 📈 XP Script
- 🔧 Upgrades Script
